📡 Server-Sent Events (SSE) Contract — POST /v1/chat/stream

Streams live RAG execution states and LLM tokens. Guarantees clean completion across all paths (technical, refusal, chit-chat, guard-blocked).

Event Payload Schema Trigger Timing
status {"stage": "guard" | "retrieval" | "generating"} Emitted at the beginning of each execution phase
sources [{"id": "doc-1", "source": "pods_autoscale.html", "section": "Metric Server Setup", "page": null, "snippet": "Before testing HPA..."}] Emitted after hybrid retrieval + TinyBERT reranking (snippet capped at 300 chars)
token {"delta": "The "} Emitted incrementally as the LLM Gateway streams answer chunks
done {"message_id": "msg-123", "model_used": "openai/gpt-oss-120b", "retrieval_mode": "rrf", "latency_ms": 1140, "usage": {"total_tokens": 940}} Emitted upon successful completion of any path (returns model_used: null if blocked)
error {"code": "rate_limited", "message": "Reasoning service rate limit reached.", "retryable": true} Emitted if an exception interrupts the pipeline (stack traces & secrets suppressed)

Standardized Error Codes

guard_blocked guard_unavailable rate_limited quota_exhausted no_context internal

  "rating": "up", // "up" | "down"
  "comment": "Accurate CLI commands provided."
}

Saved to separate feedback.db SQLite database with WAL mode enabled to avoid contention with LangGraph checkpoints.

Thread Management Endpoints

  • GET /v1/threads — List threads for current user
  • GET /v1/threads/{id} — Retrieve message history
  • DELETE /v1/threads/{id} — Delete thread & clear checkpointer

🔐 Identity & Thread Isolation

Configurable via AUTH_MODE=none|apikey|oidc:

1
Anonymous Cookie Mode (none)

Issues HTTP-only secure cookie trustrag_user_id. Automatically isolates user workspaces in demo/local mode.

2
API Key Mode (apikey)

Validates X-API-Key and scopes all thread access to the key identity.

3
Multi-Tenant Isolation Invariant

Every thread stores owner_user_id. Users guessing other UUIDs are blocked with HTTP 403 Forbidden.

Clean, accessible, enterprise interface under frontend/:

Interactive Citations
